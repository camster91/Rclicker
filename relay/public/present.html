Present a PDF from this browser

Pick a PDF of your slides, scan the QR code with your phone, and move the slides from your phone. The file stays on this computer; it is never uploaded.

How do I get a PDF of my slides?
  • PowerPoint: File → Export → Create PDF/XPS.
  • Google Slides: File → Download → PDF document.
  • Keynote: File → Export To → PDF.

A PDF shows each slide as it looks at the end: animations, transitions and videos don't play. For those, use the rclicker app for Windows.

Built for real meeting rooms

Most phone remotes need your phone and laptop on the same Wi-Fi. That rarely works at the office, a client site, a university or a conference: guest networks keep devices apart.

rclicker doesn't care. The computer and the phone each connect out to a small relay, the same way a web page loads. So it works where other remotes don't.

  • Phone on mobile data, computer on corporate Wi-Fi
  • No firewall prompts, no ports to open
  • Works through company web proxies
  • Screens stay awake while you present
  • Reconnects by itself if your phone locks
  • One phone in control. Nobody in the audience can take over.

Secure by design

End-to-end encrypted

Every command is encrypted on your phone and only unlocked by your computer (AES-256). The relay in the middle passes it along but can't read it or fake it.

The key never leaves your devices

Each session has a random 256-bit key inside the QR code. It's never sent to any server and is never saved. Close the app and the code stops working.

Can only move slides

The phone can send five commands and nothing else. It can't type, press other keys or run anything on your computer.

Only when PowerPoint is in front

By default rclicker only acts while PowerPoint is the active window, so a stray tap never lands in your email.

Questions

Does it cost anything?

No. rclicker is free.

Do I need to install an app on my phone?

No. Scanning the QR code opens the remote in Safari or Chrome. Nothing to install, no sign-in.

Does my phone need to be on the same Wi-Fi as the computer?

No. Both just need internet. The phone can use mobile data while the computer is on any network.

Windows says it protected my PC. Is that normal?

Yes, for now. rclicker is new and not yet code-signed, so Windows asks before running it. Click More info → Run anyway. If your browser blocks the download, open your downloads list and choose Keep.

My company network blocks it. What should I ask IT?

Ask them to allow HTTPS and WebSocket connections to clicker.rotmanav.ca (port 443). Nothing needs to connect into your computer.

Can someone in the audience take control?

Only one phone can control a session. Others see "Another phone is in control". The QR code hides itself once your phone connects, and New session instantly makes the old code useless.

Does it work with Google Slides or PDFs?

It's made for PowerPoint. You can untick "Only send keys when PowerPoint is the active window" to use it with other apps that move with the arrow keys.

# Rclicker 0.2.8

Malformed command IDs from a paired phone now receive a protocol error without disconnecting the session. A following valid command still works. Commands remain authenticated and encrypted.

Failed relay handshakes now report HTTP refusals, redirects and access denial accurately instead of labeling every failure as a blocked network. Authentication or relay access configuration may still require an administrator decision.

Download `rclicker.exe` for the portable app or `rclicker-win-x64.msix` for installation. The release also includes the portable ZIP and `sha256.txt`. Windows artifacts are signed by Cameron Ashley.

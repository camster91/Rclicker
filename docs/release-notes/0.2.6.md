# Rclicker 0.2.6

Maintenance release. Phone pairing and presentation controls work as in 0.2.5.

- Build checks now reject unused imports, private members and unreachable code.
- CI checkouts no longer retain GitHub credentials.
- Bash release scripts use consistent LF line endings on Windows and Linux.

Download `rclicker.exe` for the portable app or `rclicker-win-x64.msix` for
installation. The release also includes the portable ZIP and `sha256.txt`.
Windows artifacts are signed by Cameron Ashley. The existing relay is unchanged.

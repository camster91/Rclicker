# Rclicker 0.2.7

Fixes a connection race when regenerating a phone pairing session. Delayed cleanup of the previous session now stays bound to that connection, so it cannot cancel the replacement session.

Download `rclicker.exe` for the portable app or `rclicker-win-x64.msix` for installation. The release also includes the portable ZIP and `sha256.txt`. Windows artifacts are signed by Cameron Ashley.
